Editar a base institucional

O analisador utiliza o arquivo data/formacao_docentes.csv. Nesta página você pode abrir uma cópia local desse mesmo CSV, editar em formulário e salvá-lo novamente sem precisar trabalhar diretamente nas células do Excel/LibreOffice.

Ver arquivo no GitHub

Chrome/Edge: ao usar Abrir CSV para edição, o navegador mantém acesso ao arquivo escolhido e o botão Salvar no mesmo arquivo grava diretamente nele. Em navegadores que não oferecem essa função, o sistema salva um novo formacao_docentes.csv para substituição no repositório.
